# 변경 기록

## 2026-09-11

- 원본 mutmut 직접 실행의 공통 격리 연결을 독립 검토하고, 승인 코드 지문 결합 뒤 새 연결 시험 5개를 통과했습니다. 별도 새 사본의 실제 비교 실행을 시작했으며 완료된 이전 SENTINEL 검사는 재시작하지 않았습니다. 실행·정리는 기존 공통 부모가 맡고 새 관리 서비스나 플러그인 기능은 추가하지 않았습니다. 새 결과와 후보별 비교는 아직 미완료입니다.
- 실제 공개 프로젝트 재검증을 마쳤습니다. 결과 저장 오류 종료 7은 해소됐고 품질 기준 미달 종료 2와 변이 567개의 상세 기록을 회수했습니다. 원래 빌드·기본 테스트 297개 두 번·원본 보존·정리를 새로 대조했습니다. 사용 안내에는 현재 결과와 다음 직접 비교를 먼저 표시하며, 세부 지문과 이전 실패 이력은 검증 기록에 둡니다. 전체 언어 연결이나 플러그인 완료는 아닙니다.
- 비교 결과 전송의 오류 네 경계를 보완하고 독립 재검토를 마쳤습니다. 최종 부모 연결·실패 처리·입력 확인 시험 18개를 주 담당이 새로 실행한 뒤 수정본의 실제 공개 검사를 시작했습니다. 새 실행 결과는 아직 없으며, 직접 mutmut 비교·통합 연결·플러그인 완료와 구분합니다.
- 결과 기록 보완본의 두 설치 파일이 같은 내용임을 확인하고 실행 입력 26개를 준비했습니다. 외부 도구 25개는 유지했으며 새 다운로드나 공개 프로젝트 실행은 하지 않았습니다. README와 문서 시작점은 현재 작업·남은 일 위주로 줄이고, 크기·지문·준비 실패 이력은 상세 검증 기록에 분리했습니다.
- 결과 저장 직전에 알려진 사유 세 개의 형식만 연결했습니다. 제품 변경은 한 함수의 5줄이며 계산 결과·실패 기준·기록 검증은 유지했습니다. 새 실패 재현과 수정 후 통과, 주 담당의 전체 자체 시험 420개 통과를 확인했습니다. 최초 전체 시험은 일부 기록만 남아 별도 재검증 원문과 구분했으며, 실제 프로젝트 재실행과 새 배포물은 아직 없습니다.
- 수정본의 실제 공개 검사는 종료 7/evidenceInvalid로 끝났습니다. 이전과 같은 원래 빌드·전체 기본 시험 297개 두 번, 원본 보존·컨테이너 제거·사후 오류 0을 확인했습니다. 현재 상태를 원인 조사로 갱신했으며 도구 비교·통합 연결 완료로 처리하지 않았습니다.
- 수정본의 입력 연결 검토를 마치고 공개 프로젝트 재검증을 시작했습니다. 외부 도구 25개는 유지하고 자체 설치 파일 한 개만 교체했습니다. 연결 시험 61개와 독립 검토, 주 담당의 최종 연결 확인을 마쳤으며 실제 종료 결과는 아직 없습니다. 현재 실행과 이전 실패 이력을 구분해 안내합니다.
- 일반 예외를 변이 탐지 성공과 구분하도록 보완했습니다. 증거가 일치하는 일반 예외도 품질 실패로 남기며, 불확실한 결과를 정상 처리하지 않습니다. 자체 시험 417개와 주 담당의 실제 명령 시험 1개가 통과했고 독립 검토 지적은 0건입니다. 수정본의 공개 프로젝트 검증은 아직 남아 있습니다.
- README의 역할·검사 순서·통과 조건을 한글로 간단히 정리했습니다. 상세 실패 이력과 설치 파일 지문은 별도 검증 기록에 둡니다.
- README와 문서 시작점의 오래된 미구현 설명을 현재 명령·도구 연결 코드에 맞췄습니다. 구현과 공개 프로젝트 검증 완료를 구분하고 실제 검증 기록을 연결했습니다.
- 테스트 안내를 고정 Python 3.12.13·uv 0.12.9의 기존 설치를 사용하는 명령으로 고쳤습니다. 다운로드·자동 설치 없이 실행하며 준비물이 없으면 중단합니다. 이번 순서 보완 전 관련 회귀 시험은 87개 통과했고, 공개 프로젝트의 변이 결과 오류는 아직 남아 있습니다.
